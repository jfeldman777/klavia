# Совпад

Русская раскладка клавиатуры с совпадениями с английской QWERTY.

## Графические совпадения

A→А B→В C→С E→Е H→Н K→К M→М O→О P→Р T→Т X→Х Y→У

## Полусовпадения графические

R→Я N→И

## Совпадения звуковые

G→Г D→Д J→Ж Z→З L→Л U→Ю F→Ф

## Дополнительно

I→Й S→Ч

## Остальные (отдельно)

| EN | RU |
|----|----|
| Q  | П  |
| W  | Ш  |
| V  | Б  |
| [  | Ъ  |
| ]  | Ё  |
| ;  | Э  |
| '  | Ь  |
| ,  | Ц  |
| .  | Ы  |
| /  | Щ  |

Свободные латинские буквы не остаются — все 26 заняты правилами или «отдельно». Свободны только знаки раскладки, уже занятые выше: `[ ] ; ' , . /`.

## Запуск

```bash
npm install
npm run dev -- -p 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).
