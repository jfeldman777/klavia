# Klavia / Совпад

Русская раскладка по совпадениям с английской QWERTY + миниклавиатура на **Q**.
Иврит на тех же клавишах; концевые формы — **J**, затем буква.

Сайт (после деплоя Pages): https://jfeldman777.github.io/klavia/

## На любом компьютере

### 1. Веб (без установки)
Откройте приложение в браузере → поле «Проверка набора».  
**Pause** (или кнопки над клавиатурой) листает по кругу:

- **РУ** — стандарт ЙЦУКЕН
- **АНГЛ** — стандарт QWERTY
- **ИВРИТ** — стандартная ивритская
- **РУ-КЛАВИА** — Совпад (`Q` → цифра)
- **ИВРИТ-КЛАВИА** — карта Совпад, справа налево (`J` затем буква)

### 2. Windows (во всех программах)
1. Установите [AutoHotkey v2](https://www.autohotkey.com/) (именно v2).
2. Для стандартного **ИВРИТ**: Параметры → Время и язык → Язык и регион → добавьте «Иврит».
3. Скачайте `klavia.ahk` на сайте (блок «Установка») и откройте двойным щелчком.
4. **Pause** листает: РУ → АНГЛ → ИВРИТ → РУ-КЛАВИА → ИВРИТ-КЛАВИА. Правый клик по иконке в трее — выбрать сразу.
5. Автозапуск: Win+R → `shell:startup` → ярлык на `klavia.ahk`.

РУ-КЛАВИА: `Q` затем цифра 2–0, Б на V. ИВРИТ-КЛАВИА: `J` затем буква концевой формы.

### 3. macOS
Скачайте `Klavia.keylayout` или `Klavia-Hebrew.keylayout` → `~/Library/Keyboard Layouts/` → перелогиньтесь → добавьте источник ввода.

### 4. Linux
Скачайте `klavia-linux.txt` или `klavia-he-linux.txt`, следуйте инструкции внутри (xkb в `~/.config/xkb`).

## Совпадения (русский)

| Тип | Пары |
|-----|------|
| Графика | A→А B→В C→С E→Е H→Н K→К M→М O→О P→Р T→Т X→Х Y→У |
| Полусовпадения | R→Я N→И |
| Звук | G→Г D→Д J→Ж Z→З L→Л U→Ю F→Ф |
| Доп. | I→Й S→Ч V→Б |
| Q-слой | 2П 3Ш 4Щ 5Ц 6Ъ 7Ы 8Ь 9Э 0Ё |

## Иврит

Те же физические клавиши, что у «Совпад»:

| Клавиша | Буква |
|---------|-------|
| A | א алеф |
| B | ב бет |
| G | ג гимел |
| D | ד далет |
| E | ה хей |
| W | ו вав |
| Z | ז зайн |
| X | ח хет |
| T | ט тет |
| I | י йуд |
| K | כ каф |
| L | ל ламед |
| M | מ мем |
| N | נ нун |
| O | ס самех |
| Y | ע айн |
| F | פ фей |
| C | צ цади |
| Q | ק коф |
| P | ר реш |
| S | ש шин / син |
| V | ת тав |

Концевые (сначала **J**, потом буква): J+K ך · J+M ם · J+N ן · J+F ף · J+C ץ
