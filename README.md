# Совпад

Русская раскладка клавиатуры с тремя слоями совпадений с английской QWERTY.

## Графические совпадения

| EN | RU |
|----|----|
| O  | О  |
| P  | Р  |
| B  | В  |
| M  | М  |
| A  | А  |
| C  | С  |
| E  | Е  |
| H  | Н  |
| K  | К  |
| T  | Т  |
| X  | Х  |
| Y  | У  |

## Полусовпадения графические

| EN | RU |
|----|----|
| R  | Я  |
| N  | И  |

## Совпадения звуковые

| EN | RU |
|----|----|
| G  | Г  |
| D  | Д  |
| J  | Ж  |
| Z  | З  |
| L  | Л  |
| U  | Ю  |

Остальные буквы (Б, Й, П, Ф, …) задаются отдельно в редакторе.

## Возможности

- Интерактивная клавиатура с цветовой легендой по типам совпадений
- Назначение букв кликом, блокировка базовых соответствий
- Проверка набора в браузере
- Экспорт в JSON и фрагмент Linux xkb
- Сохранение в `localStorage`

## Запуск

```bash
npm install
npm run dev -- -p 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).
