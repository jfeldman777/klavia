# Совпад

Русская раскладка клавиатуры, где **графически похожие** буквы стоят на тех же клавишах, что и в английской QWERTY.

Примеры совпадений:

| EN | RU |
|----|----|
| O  | О  |
| P  | Р  |
| B  | В  |
| M  | М  |
| A  | А  |
| C  | С  |
| E  | Е  |
| H  | Н  |
| K  | К  |
| T  | Т  |
| X  | Х  |
| Y  | У  |

Остальные буквы (Б, Г, Д, Ж, …) задаются отдельно в редакторе.

## Возможности

- Интерактивная клавиатура с подсветкой совпадений и своих назначений
- Назначение букв кликом, блокировка совпадений
- Проверка набора прямо в браузере (перехват физических клавиш)
- Экспорт в JSON и фрагмент Linux xkb
- Сохранение в `localStorage`

## Запуск

```bash
npm install
npm run dev -- -p 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).
