# Klavia / Совпад

Русская раскладка по совпадениям с английской QWERTY + миниклавиатура на **Q**.

Сайт (после деплоя Pages): https://jfeldman777.github.io/klavia/

## На любом компьютере

### 1. Веб (без установки)
Откройте приложение в браузере → поле «Проверка набора».  
`Q` → цифра `1`–`0` для оставшихся букв.

### 2. Windows (во всех программах)
1. Установите [AutoHotkey v2](https://www.autohotkey.com/)
2. Скачайте `klavia.ahk` на сайте (блок «Установить на ПК») или из релизов
3. Запустите файл  
   - `Pause` — вкл/выкл  
   - `Q` затем цифра — слой оставшихся букв

### 3. macOS
Скачайте `Klavia.keylayout` → `~/Library/Keyboard Layouts/` → перелогиньтесь → добавьте источник ввода.

### 4. Linux
Скачайте `klavia-linux.txt`, следуйте инструкции внутри (xkb в `~/.config/xkb`).

## Совпадения

| Тип | Пары |
|-----|------|
| Графика | A→А B→В C→С E→Е H→Н K→К M→М O→О P→Р T→Т X→Х Y→У |
| Полусовпадения | R→Я N→И |
| Звук | G→Г D→Д J→Ж Z→З L→Л U→Ю F→Ф |
| Доп. | I→Й S→Ч |
| Q-слой | 1Б 2П 3Ш 4Щ 5Ц 6Ъ 7Ы 8Ь 9Э 0Ё |
