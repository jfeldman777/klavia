# Совпад

Русская раскладка: совпадения с EN + миниклавиатура на **Q** для оставшихся букв.

## Основная раскладка

- **Графика:** A→А B→В C→С E→Е H→Н K→К M→М O→О P→Р T→Т X→Х Y→У
- **Полусовпадения:** R→Я N→И
- **Звук:** G→Г D→Д J→Ж Z→З L→Л U→Ю F→Ф
- **Доп.:** I→Й S→Ч

## Миниклавиатура (Q)

Q не печатает букву — открывает слой. Затем цифра:

| Q → | Буква |
|-----|-------|
| 1 | Б |
| 2 | П |
| 3 | Ш |
| 4 | Щ |
| 5 | Ц |
| 6 | Ъ |
| 7 | Ы |
| 8 | Ь |
| 9 | Э |
| 0 | Ё |

Esc закрывает слой. В редакторе можно переназначить слоты.

## Запуск

```bash
npm install
npm run dev -- -p 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).
